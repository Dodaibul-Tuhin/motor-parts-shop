# Motor Parts Shop

A web-based inventory and sales management system for a motor parts store, built as an intern project using **PHP**, **MySQL** and **Bootstrap 5**.

## About the Project

Small shop owners often track stock, customer dues and expenses in notebooks, which makes it hard to know what is in stock, who owes money and how the business is doing. This system puts all of that in one admin panel. The owner can manage products, brands and categories, create sales invoices, track customer dues and record daily expenses, with a live dashboard summarizing the business at a glance.

The interface is in Bangla, with an English-friendly codebase.

## Features

- Secure admin login with hashed passwords
- Product management with brand, category, cost price, selling price and stock
- Brand and category management
- Sales invoices with multiple items, automatic total, paid and due calculation
- Automatic stock deduction after each sale, with low stock alerts
- Expense tracking
- Dashboard showing total products, today's sales, total sales, expenses and dues

## Built With

- MySQL
- Bootstrap 5
- JavaScript
